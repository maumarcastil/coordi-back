# Coordi Backend

Backend API construido con Fastify y TypeScript.

## Requisitos

- Node.js 18+
- pnpm

## Instalación

```bash
pnpm install
```

## Scripts

```bash
# Desarrollo con hot-reload
pnpm dev

# Compilar para producción
pnpm build

# Ejecutar en producción
pnpm start
```

## Estructura del proyecto

```
src/
└── index.ts    # Punto de entrada del servidor
```
